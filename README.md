# Ландшафт: CPU и OpenGL

Учебное приложение для генерации и визуализации ландшафта на **C# / .NET 10 / Avalonia**.
Работает на macOS. Геометрия, генераторы, программный растеризатор и шейдеры написаны в проекте.

## Запуск

Открой **`Terrain.slnx`** из корня репозитория в Rider и выбери `Terrain.App` для запуска.
Старого Windows Forms-решения больше нет.

В терминале из корня репозитория:

```sh
./run-mac.command
```

Скрипт находит .NET SDK в PATH или внутри установленного `/Applications/Rider.app`.
Его также можно открыть двойным щелчком в Finder. При первой сборке нужен интернет
для NuGet. Требуется .NET 10 SDK; `global.json` допускает стабильные feature bands 10.0.

Если `dotnet` доступен в PATH:

```sh
dotnet run --project src/Terrain.App -c Release
```

## Структура решения

```text
Terrain.slnx
src/
  Terrain.Core/                  # Математика, данные, CPU-рендер; без UI-зависимостей
    Generation/                  # Холмы, Perlin, Simplex, Diamond–Square
    Models/                      # Карта высот, вершины, сетка
    Rendering/                   # Преобразования модели, CPU-растеризатор
      Shadows/                   # Проекция света, карта теней, PCF
  Terrain.App/                   # Окно и интеграция с платформой
    Views/                       # Интерфейс и обработка действий пользователя
    Controls/                    # OpenGL-компонент сцены
    Rendering/OpenGl/            # Привязки к OpenGL
    Services/                    # Чтение/сохранение изображений и показ bitmap
    Properties/                  # Доступ интеграционных проверок к internal API
tests/
  Terrain.Core.Tests/            # xUnit; доступны в Test Explorer / Unit Tests IDE
  Terrain.App.SmokeTests/        # Отдельный запуск настоящего окна и проверка GPU
docs/                          # Формулы, устройство и результаты проверок
Карты высот/                    # Исходные карты + Generated с новой картой
Примеры/                        # Исходные примеры + Generated с 3D-превью
РПЗ НАЙДЕНЫШЕВ.pdf
ПРЕЗЕНТАЦИЯ КП.pdf
```

`Directory.Build.props` задаёт общие настройки C#, `Directory.Packages.props` —
версии NuGet-пакетов, `.editorconfig` — форматирование. Сборочные каталоги `bin/obj`
и локальные настройки IDE исключены из Git. У Core нет зависимости от Avalonia,
а приложение не зависит от тестовых проектов.

Подробнее: [архитектура](docs/architecture.md), [математика и алгоритмы](docs/algorithms.md).

## Возможности и управление

- Два режима: свой CPU-растеризатор с Z-буфером и OpenGL с собственными шейдерами.
- Четыре генератора: холмы, Perlin, Simplex, Diamond–Square; воспроизводимый seed.
- Сглаживание высот, «долина», настройки шума, масштаб высоты рельефа.
- Импорт BMP/PNG, включая прямоугольные карты, предпросмотр высот.
- Вращение по трём осям и шагами ±90°, перенос, приближение и ползунок положения солнца: восход → зенит → закат.
- Падающие тени и смягчение их краёв в обоих режимах.
- Экспорт текущей сцены в PNG/BMP; OpenGL сохраняет настоящий framebuffer.
- Отдельные замеры генерации и построения кадра.

Левая кнопка мыши вращает ландшафт, Shift + левая или правая кнопка переносит,
колесо/жест прокрутки масштабирует. Камера фиксирована, солнце перемещается отдельным ползунком: при повороте модели
её освещение и падающие тени меняются. Переключение CPU/OpenGL сохраняет сцену.

Настройки появляются только для выбранного генератора: количество холмов — для
холмового, октавы/частота/затухание — для шумов, шероховатость и подсказка размера —
для Diamond–Square. Размер, seed, сглаживание и «долина» общие. Значения сохраняются
при переключении. Панель прокручивается: свет и экспорт находятся ниже генерации.

Генерация поддерживает размеры 2…1025, импорт — 2…2049 по каждой стороне.
Для Diamond–Square нужен размер `2ⁿ + 1`: например, 65, 129, 257, 513, 1025.
Для начала удобно 129×129. [Новая карта горного рельефа](Карты%20высот/Generated/mountains-2026-heightmap.png)
и [её 3D-превью](Примеры/Generated/mountains-2026-preview.png) сохранены отдельно.

## Проверки

```sh
dotnet build Terrain.slnx -c Release
dotnet test Terrain.slnx -c Release
./run-mac.command --smoke-test
```

Математические проверки запускаются через xUnit и видны по отдельности в IDE.
Они проверяют генераторы, сглаживание, геометрию, глубину и тени.

Smoke-проверки находятся в отдельном исполняемом тестовом проекте. Они открывают
окно, сравнивают CPU/GPU, проверяют поворот модели, тени, изменение размера, экспорт
и импорт карт из репозитория, затем закрывают окно. Код этих проверок не входит
в приложение. Для запуска нужна графическая сессия Mac.

Кадры и отчёт сохраняются в `Path.GetTempPath()/terrain-smoke` — обычно это
`$TMPDIR/terrain-smoke`. Подробности: [результаты проверок](docs/validation.md).

## Ограничения

Проверено на Mac с Apple Silicon; Intel Mac отдельно не проверялся. Avalonia
закреплена на 11.3.13 с явным OpenGL backend macOS. OpenGL у Apple объявлен
устаревшим API; CPU-режим доступен независимо от нашего GL-рендера.

Камера ортографическая. Освещение — ambient + Lambert, без бликов. Карта теней
1024×1024 строится при изменении модели, её поворота/высоты или направления света.
При переносе, приближении, изменении окна и фильтрации она переиспользуется.
PCF 3×3 сглаживает границу тени, но не моделирует физическую полутень. Конечное
разрешение карты теней заметно при сильном приближении.

Импорт использует яркость RGB с точностью 8 бит; это не GIS-приложение для 16-битных
DEM. Seed воспроизводит карту в рамках данной реализации/runtime. Побитовое
совпадение со старой DLL и будущими версиями .NET не гарантируется.

Кадры строятся при изменениях. Показатель «мс» — время подготовки кадра, не FPS
монитора. GPU-замер включает передачу геометрии и ожидание GPU; CPU-замер —
преобразования, растеризацию и загрузку bitmap.

Солнце движется по дуге на фоне неба одновременно с перемещением ползунка.
Его направление управляет освещением и падающими тенями независимо от поворота
модели. Небо, солнечный диск и свечение рисуются собственными формулами в CPU
и OpenGL и сохраняются вместе со сценой в PNG/BMP.
