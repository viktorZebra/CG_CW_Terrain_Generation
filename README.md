# Ландшафт: CPU и OpenGL

В режиме **Мир** клавиша **M** открывает карту с положением и направлением
камеры; **M / Esc** закрывает её. Ближний рельеф — 129×129 точек на участок,
средний — 65×65, дальний — 33×33. Лунное освещение усилено вдвое.
[Подробнее о детализации и карте](docs/world-lod.md).

География мира теперь следует климату: **снежный север → лес с болотными
участками → степь → пустынный юг**. Границы неровные и плавные, рисунок болот
и рельеф случайный для каждого нового мира.

Учебное приложение для генерации и визуализации ландшафта на **C# / .NET 10 / Avalonia**.
Работает на macOS. Геометрия, генераторы, программный растеризатор и шейдеры написаны в проекте.

## Готовые примеры визуального обновления

Этапы 6–10 завершены: осыпи, снег, дымка, отдельная вода, углублённые русла,
ускорение OpenGL и необязательная тепловая эрозия. [Семь проектов с превью](Карты%20высот/Upgrade/README.md)
открываются через «Открыть проект…». Для просмотра без запуска приложения —
[локальная HTML-галерея](Карты%20высот/Upgrade/index.html).
[Замеры скорости и решения по оптимизации](docs/performance.md).

## Запуск

Открой **`Terrain.slnx`** из корня репозитория в Rider и выбери `Terrain.App` для запуска.
Старого Windows Forms-решения больше нет.

В терминале из корня репозитория:

```sh
./run-mac.command
```

Скрипт находит .NET SDK в PATH или внутри установленного `/Applications/Rider.app`.
Его также можно открыть двойным щелчком в Finder. При первой сборке нужен интернет
для NuGet. Требуется .NET 10 SDK; `global.json` допускает стабильные feature bands 10.0.

Если `dotnet` доступен в PATH:

```sh
dotnet run --project src/Terrain.App -c Release
```

## Структура решения

```text
Terrain.slnx
src/
  Terrain.Core/                  # Математика, данные, CPU-рендер; без UI-зависимостей
    Generation/                  # Холмы, Perlin, Simplex, Diamond–Square
    Models/                      # Карта высот, вершины, сетка
    Rendering/                   # Преобразования модели, CPU-растеризатор
      Shadows/                   # Проекция света, карта теней, PCF
  Terrain.App/                   # Окно и интеграция с платформой
    Views/                       # Интерфейс и обработка действий пользователя
    Controls/                    # OpenGL-компонент сцены
    Rendering/OpenGl/            # Привязки к OpenGL
    Services/                    # Чтение/сохранение изображений и показ bitmap
    Properties/                  # Доступ интеграционных проверок к internal API
tests/
  Terrain.Core.Tests/            # xUnit; доступны в Test Explorer / Unit Tests IDE
  Terrain.App.SmokeTests/        # Отдельный запуск настоящего окна и проверка GPU
docs/                          # Формулы, устройство и результаты проверок
Карты высот/                    # Исходные карты + Generated с новой картой
Примеры/                        # Исходные примеры + Generated с 3D-превью
РПЗ НАЙДЕНЫШЕВ.pdf
ПРЕЗЕНТАЦИЯ КП.pdf
```

`Directory.Build.props` задаёт общие настройки C#, `Directory.Packages.props` —
версии NuGet-пакетов, `.editorconfig` — форматирование. Сборочные каталоги `bin/obj`
и локальные настройки IDE исключены из Git. У Core нет зависимости от Avalonia,
а приложение не зависит от тестовых проектов.

Подробнее: [архитектура](docs/architecture.md), [математика и алгоритмы](docs/algorithms.md).

## Возможности и управление

- Два режима: свой CPU-растеризатор с Z-буфером и OpenGL с собственными шейдерами.
- Четыре генератора: холмы, Perlin, Simplex, Diamond–Square; воспроизводимый seed.
- Сглаживание высот, «долина», настройки шума, масштаб высоты рельефа.
- Импорт BMP/PNG, включая прямоугольные карты, предпросмотр высот.
- Вращение по трём осям и шагами ±90°, перенос, приближение и ползунок положения солнца: восход → зенит → закат.
- Падающие тени и смягчение их краёв в обоих режимах.
- Экспорт текущей сцены в PNG/BMP; OpenGL сохраняет настоящий framebuffer.
- Отдельные замеры генерации и построения кадра.

Левая кнопка мыши вращает ландшафт, Shift + левая или правая кнопка переносит,
колесо/жест прокрутки масштабирует. Камера управляется W/S (вперёд/назад) и A/D (поворот на месте);
для управления щёлкните по сцене. Солнце перемещается отдельным ползунком: при повороте модели
её освещение и падающие тени меняются. Переключение CPU/OpenGL сохраняет сцену.

Настройки появляются только для выбранного генератора: количество холмов — для
холмового, октавы/частота/затухание — для шумов, шероховатость и подсказка размера —
для Diamond–Square. Размер, seed, сглаживание и «долина» общие. Значения сохраняются
при переключении. Панель прокручивается: свет и экспорт находятся ниже генерации.

Генерация поддерживает размеры 2…1025, импорт — 2…2049 по каждой стороне.
Для Diamond–Square нужен размер `2ⁿ + 1`: например, 65, 129, 257, 513, 1025.
Для начала удобно 129×129. [Новая карта горного рельефа](Карты%20высот/Generated/mountains-2026-heightmap.png)
и [её 3D-превью](Примеры/Generated/mountains-2026-preview.png) сохранены отдельно.

## Проверки

```sh
dotnet build Terrain.slnx -c Release
dotnet test Terrain.slnx -c Release
./run-mac.command --smoke-test
```

Математические проверки запускаются через xUnit и видны по отдельности в IDE.
Они проверяют генераторы, сглаживание, геометрию, глубину и тени.

Smoke-проверки находятся в отдельном исполняемом тестовом проекте. Они открывают
окно, сравнивают CPU/GPU, проверяют поворот модели, тени, изменение размера, экспорт
и импорт карт из репозитория, затем закрывают окно. Код этих проверок не входит
в приложение. Для запуска нужна графическая сессия Mac.

Кадры и отчёт сохраняются в `Path.GetTempPath()/terrain-smoke` — обычно это
`$TMPDIR/terrain-smoke`. Подробности: [результаты проверок](docs/validation.md).

## Ограничения

Проверено на Mac с Apple Silicon; Intel Mac отдельно не проверялся. Avalonia
закреплена на 11.3.13 с явным OpenGL backend macOS. OpenGL у Apple объявлен
устаревшим API; CPU-режим доступен независимо от нашего GL-рендера.

Камера перспективная. «Сбросить вид» возвращает её в исходное положение. Освещение — ambient + Lambert, без бликов. Карта теней
1024×1024 строится при изменении модели, её поворота/высоты или направления света.
При переносе, приближении, изменении окна и фильтрации она переиспользуется.
PCF 3×3 сглаживает границу тени, но не моделирует физическую полутень. Конечное
разрешение карты теней заметно при сильном приближении.

Импорт использует яркость RGB с точностью 8 бит; это не GIS-приложение для 16-битных
DEM. Seed воспроизводит карту в рамках данной реализации/runtime. Побитовое
совпадение со старой DLL и будущими версиями .NET не гарантируется.

Кадры строятся при изменениях. Показатель «мс» — время подготовки кадра, не FPS
монитора. GPU-замер включает передачу геометрии и ожидание GPU; CPU-замер —
преобразования, растеризацию и загрузку bitmap.

Солнце движется по дуге на фоне неба одновременно с перемещением ползунка.
Его направление управляет освещением и падающими тенями независимо от поворота
модели. Небо, солнечный диск и свечение рисуются собственными формулами в CPU
и OpenGL и сохраняются вместе со сценой в PNG/BMP.

Визуальное развитие отслеживается в [плане](VISUAL_UPGRADE_PLAN.md). Уже добавлена
окраска по высоте и уклону: трава на пологих участках, скалы на обрывах, снег на
высоких пологих площадках, плавные переходы и воспроизводимые вариации оттенков.

При запуске выбран **OpenGL**. В разделе **«Реки и озёра»** можно изменить уровень
моря (нормированная высота 0–1) и густоту речной сети, затем нажать **«Обновить воду»**.
Отключение переключателя показывает исходный сухой рельеф. Исходная карта и seed
при этом сохраняются; камера остаётся на месте. Впадины заполняются озёрами до
перелива, ручьи сливаются и расширяются вниз по течению. Около воды добавлены
берега и влажные оттенки травы. Реки пока окрашены без движения воды.

Раздел **«Растительность и камни»** добавляет объёмные ели, лиственные деревья
и валуны. Выберите плотность леса и нажмите **«Обновить лес и камни»**; камера
и исходная карта сохраняются. При плотности 0 остаются только камни; отключение
раздела убирает все объекты. Деревья избегают воды, крутых склонов и снежных высот,
а их количество видно под миниатюрой карты. Все объекты отбрасывают тени и
попадают в экспорт PNG/BMP. Для повторения используйте тот же seed и настройки.

**«Сохранить проект…»** записывает файл `*.terrain.json`, **«Открыть проект…»**
восстанавливает его. Внутри — исходная карта высот, seed и применённые параметры
генератора, воды и объектов, положение камеры, повороты, солнце, тени и режим
CPU/OpenGL. Исходный PNG/BMP не нужен: карта встроена в проект без потери
точности float. Для сохранения новых значений настроек сначала примените их
кнопками генерации/обновления. **«Сохранить изображение PNG / BMP»** по-прежнему
экспортирует готовый кадр.

Текущий формат проекта — версия 2; файлы версии 1 поддерживаются. Несовместимые версии и повреждённые файлы
отклоняются до замены текущей сцены. Объекты и вода пересчитываются при открытии
из сохранённых высот и параметров; это формат воспроизводимой сцены, а не архив
готовой треугольной геометрии.

«Высота рельефа» изменяет землю и положение оснований деревьев/камней.
Размер и пропорции самих объектов сохраняются, их тени обновляются.

В переключателе **«Обзор / Прогулка»** доступен вид с земли:

- В «Прогулке» рельеф горизонтален, камера начинает в центре карты.
- Щёлкните по сцене и отпустите кнопку: движение мыши или одного пальца по трекпаду поворачивает взгляд на 360° и почти вертикально вверх/вниз. Удерживать кнопку не нужно.
- W/S — идти по земле вперёд/назад, A/D — поворот на месте. Взгляд вверх не вызывает полёт.
- Esc освобождает курсор; потеря фокуса окна также прекращает захват и движение.
- Стрелка-язычок у левого края сцены сворачивает настройки и расширяет сцену.
  Нажмите её повторно, чтобы вернуть панель; при захваченном взгляде сначала нажмите Esc.
- Движение ограничено только границами карты. По воде и любым склонам можно
  идти; над озёрами камера следует поверхности воды. Столкновений с объектами нет.
- «Сбросить вид» в прогулке возвращает в центр карты, в том числе полностью затопленной.
- Возврат в «Обзор» восстанавливает его камеру и поворот модели. Положение
  прогулочной камеры также запоминается; оба вида сохраняются в проекте.

В прогулке солнечный диск совпадает с направлением света в мире: восход и закат
у горизонта, зенит над головой. Холм может заслонить солнце. Свободный захват мыши
реализован для macOS; в обзоре сохранено прежнее управление мышью.

Старт прогулки — центр карты. При выходе за край движение ограничивается
границей; вдоль края можно продолжать идти.

### Климат и биомы

Включены по умолчанию для новых карт. «Климат» задаёт холодную или тёплую
местность, «Влажность» — сухую или влажную. После изменения нажмите
**«Обновить окружение»**: обновится поверхность текущей карты, камера сохранится.
Горы и русла не меняются. Биомы плавно смешиваются: луг, влажная лесная зона,
степь, альпийский луг и снег; скалы и берега учитываются отдельно.

При отключённой воде фоновая влажность продолжает работать. Солнце меняет
освещение, но не климат. Влажные зоны получают более густой лес, степи — редкие деревья; в прохладе чаще
растут ели, в тепле — лиственные деревья. Альпийские и снежные зоны остаются без леса.
Проект v4 сохраняет применённый климат, его seed и режим размещения леса. Старые проекты v1/v2
открываются с прежней палитрой; включить биомы можно явно и обновить окружение.

Проекты v1–v3 сохраняют прежнее размещение объектов. Явное обновление окружения
включает новый расчёт леса; без биомов используется прежнее размещение.
«Плотность леса» регулирует число деревьев в пригодных местах, сохраняя просветы,
минимальные расстояния и запрет воды, снега и обрывов. Изменение высоты рельефа
по-прежнему не растягивает деревья и камни.

### Кустарники

Новые карты включают два вида небольших объёмных кустов. Переключатель
«Кустарники» позволяет убрать их независимо от леса; ползунок задаёт плотность,
кнопка «Обновить кустарники» применяет её к текущей карте. Кусты предпочитают
луга и влажные зоны, занимают просветы и оставляют свободными берега.
Их изменение не переставляет деревья и камни, если остальные настройки прежние.

Проект v5 хранит применённую плотность, лимит и отдельный seed кустарников.
Проекты v1–v4 открываются без кустов; включить их можно явно. Для новых сцен
лимит — 600 кустов. Экспорт и оба рендера отображают их с общими тенями.

## Панель настроек

Настройки разделены на вкладки **Карта**, **Природа** и **Вид**. Карточки внутри
вкладок можно сворачивать нажатием на заголовок. «Карта» содержит генератор,
эрозию, сведения о высотах и файлы; «Природа» — воду, растительность, камни
и климат; «Вид» — положение модели, солнце, атмосферу, тени и управление камерой.
Режим навигации и выбор CPU/OpenGL всегда доступны над вкладками. Язычок
у сцены по-прежнему скрывает и возвращает всю панель.

## Автоматический режим «Мир»

В верхнем переключателе выбери **Мир**. Новый мир создаётся случайно, без ввода
параметров, и сразу включает прогулку. Загрузку можно отменить; при выходе
возвращается исходная карта редактора.

Пять биомов: лес, пустыня с дюнами, зимнее плато с отдельными горами, болотные низины и степь.
С зимних склонов на юг спускаются три реки с вырезанными руслами; они видны на карте по M.
W/S — вперёд/назад, A/D — шаг влево/вправо; щелчок по сцене — взгляд мышью,
Esc — освободить курсор. Солнце проходит от восхода до заката за **5 минут**,
затем наступает **3 минуты ночи** с луной и звёздами. Цикл повторяется.
По небу движутся полупрозрачные облака со случайными плавными формами.
Они окрашиваются на закате и темнеют ночью; движение продолжается через границу суток.

«Создать другой мир» запускает новую генерацию. Мир строится участками вокруг
камеры с большим запасом впереди и ограниченным кешем. При входе выбран OpenGL;
CPU тоже поддерживается, но медленнее. Автоматический мир пока не сохраняется
в файлы проектов обычных карт.
