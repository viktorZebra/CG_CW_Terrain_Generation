# Автоматический мир: снимки

Снимки обновлены для широтной географии: сверху снежный север, в середине лес
с отдельными болотами, ниже степь и пустыня. Биомы больше не расходятся секторами
от центра. M показывает эту же географию в текущем случайном мире.

[Карта по M с положением камеры](09-world-map-preview.png) снята в отдельном
случайном запуске: регионы отличаются от фиксированного тестового мира ниже.
Остальные снимки обновлены с LOD: 129×129 точек рядом, 65×65 на средней
дистанции, 33×33 вдали. Освещение поверхности ночью увеличено вдвое.

В приложении выбери **Мир** в переключателе «Обзор / Прогулка / Мир».
При каждом входе создаётся новый случайный мир. Эти PNG — снимки тестового
мира с внутренним seed 20260909, а не карты высот для импорта.

[Результаты проверки и замеры](validation.txt).
День длится 5 минут, ночь — 3 минуты. Исходная карта возвращается после
выхода из мира; сохранение автоматического мира пока не реализовано.
