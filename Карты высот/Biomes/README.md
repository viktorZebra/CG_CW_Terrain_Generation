# Готовые карты с биомами

В приложении нажмите **«Открыть проект…»** и выберите `.terrain.json`.
Он содержит точные исходные высоты, климат, seed, воду, лес, камеру и солнце.
Сразу выбран OpenGL; после открытия можно переключиться в «Прогулку».

`*-preview.png` — вид готовой сцены, отрисованный собственным CPU-рендером.
`*-heightmap.png` — обычная чёрно-белая карта высот для кнопки «Загрузить карту».
PNG высот не хранит биомы и округляет высоты до 8 бит: для точного готового
примера открывайте именно проект, а не PNG.

Все карты 129×129, плотность леса 75%, море 0.02, лес по биомам включён.
Климат и влажность указаны в шкале интерфейса 0–100.

| Проект | Что смотреть | Основа / seed | Климат / влажность |
| --- | --- | --- | --- |
| [01-wet-forest](01-wet-forest.terrain.json) | Влажная лесная долина, 190 деревьев | Diamond–Square / 42 | 90 / 95 |
| [02-dry-steppe](02-dry-steppe.terrain.json) | Сухая степь, редкие деревья у воды (69) | Та же карта / 42 | 90 / 5 |
| [03-alpine-snow](03-alpine-snow.terrain.json) | Снежные высоты, альпийские участки и лес ниже (67) | Та же карта / 42 | 48 / 65 |
| [04-meadow-hills](04-meadow-hills.terrain.json) | Пологие зелёные холмы с рощами (205 деревьев) | Hills / 17, смягчённые высоты | 85 / 43 |
| [05-cool-pine](05-cool-pine.terrain.json) | Прохладная влажная местность, хвойный и смешанный лес (277) | Perlin / 73, смягчённые высоты | 67 / 85 |
| [06-mixed-valleys](06-mixed-valleys.terrain.json) | Контраст долин, скальных склонов и редкого леса (21) | Simplex / 156 | 78 / 60 |

Первые три проекта содержат абсолютно одинаковые высоты, воду, камеру и солнце:
удобно сравнивать только влияние климата. На №1 и №2 отличается лишь влажность.

Подготовка №4: Hills, 90 холмов, сглаживание; высота `0.10 + 0.12 × h`.
Подготовка №5: Perlin, 3 октавы, частота 2, сглаживание; высота `0.10 + 0.35 × h`.
Они сохранены как готовые высоты без привязки к генератору, чтобы повторное
открытие точно сохраняло обработанный рельеф. №6: Simplex, 3 октавы, частота 2,
сглаживание и «Долина». Остальные параметры генераторов стандартные.

Все шесть проектов проверены чтением обратно через SceneFiles и точным
совпадением восстановленных вершин с исходной сценой. Все превью просмотрены.
Это примеры для формата v4 и расчётов пунктов 5.1–5.2; будущие явные обновления
окружения могут применять более новые алгоритмы.
