# Визуальное обновление: готовые сцены

Запусти `./run-mac.command`, выбери **«Открыть проект…»** и открой `.terrain.json`.
Каждый файл содержит карту, применённые настройки, камеру и солнце; загрузка
одной картинки высот эти настройки не восстанавливает. Рядом лежат PNG-превью.
Для быстрого просмотра всех изображений открой [галерею](index.html) в браузере.

Во всех примерах одна исходная альпийская карта и одинаковый ракурс: изменения
можно сравнить без влияния другого seed. Шаги постепенно добавляют эффекты.

| Порядок | Проект | Что посмотреть |
|---|---|---|
| 6 | [Осыпи и снег](06-details.terrain.json) | Группы камней у склонов и неоднородные снежные пятна |
| 7 | [Атмосфера](07-atmosphere.terrain.json) | Дальние склоны мягче; попробуй выключить дымку и переместить солнце |
| 8.1 | [Отдельная вода](08-1-water.terrain.json) | Поверхность озёр и рек построена отдельно от дна |
| 8.2 | [Русла](08-2-channels.terrain.json) | Углубление рабочей земли, согласованные берега и основания объектов |
| 9 | [Быстрые тени](09-fast-shadows.terrain.json) | Та же геометрия с тенями 256; сравни с предыдущей сценой и покрути камеру |
| 10, до | [Исходные склоны](10-before.terrain.json) | Контрольная сцена для сравнения эрозии |
| 10, после | [Эрозия](10-erosion.terrain.json) | 40 итераций, сила 0.45; материал переносится с крутых склонов |

Эрозия по умолчанию выключена. В последнем проекте её можно выключить, чтобы
вернуть исходные высоты. После изменения рельефа вода и окружение перестраиваются.
Вода пока непрозрачная и неподвижная; рисунок берегов зависит от разрешения карты.
Этап 9 ускоряет отображение, поэтому нового типа объектов в нём нет.

Превью получены собственным CPU-рендером, не генерацией изображений ИИ.
Для повторного создания конкретного примера из корня:

```sh
dotnet run --project tools/Terrain.Gallery -- 10-erosion
```

Имена стадий совпадают с именами файлов без `.terrain.json`.
