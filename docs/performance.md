# Замеры этапа 9

На текущем Mac измерены карты 129×129, 257×257 и 513×513, плотности леса
0.15/0.85, тени включены/выключены. Для каждого сочетания — статичный кадр,
движение камеры, солнца и перестройка окружения: 48 строк в каждом файле.

- [До оптимизации](performance-before.csv)
- [После оптимизации](performance-after.csv)

Кадр 860×812, карта теней 512×512, Perlin (частота 2, три октавы), отдельная
вода, русла, биомы, кусты и осыпь. Столбец `prepare_ms` — отдельная подготовка
сетки; `cpu_ms`/`opengl_ms` — кадр. GPU-замер включает обновление геометрии при
необходимости и `glFinish`, но исключает чтение изображения для сравнения.
`managed_bytes` — живой managed heap после GC, не RSS процесса и не видеопамять.
Это единичные замеры после прогрева, а не статистическая гарантия FPS.

Пример: 513×513, плотность 0.85, тени включены, миллисекунды:

| Сценарий | CPU до | CPU после | OpenGL до | OpenGL после |
|---|---:|---:|---:|---:|
| Статика | 124.18 | 50.51 | 78.89 | 2.53 |
| Камера | 129.67 | 111.87 | 81.50 | 2.78 |
| Солнце | 188.77 | 169.16 | 120.87 | 78.80 |
| Окружение | 175.75 | 155.41 | 116.68 | 81.17 |

Основная обнаруженная затрата — повторная CPU-проекция всей сетки для OpenGL
и загрузка её заново при движении камеры. Теперь GPU хранит мировые вершины,
а собственный vertex shader выполняет проекцию и передаёт отсечение OpenGL.
Изменения камеры передаются uniforms; повторной загрузки буферов нет.
Солнце с тенями и перестройка окружения остаются дороже: меняются производные
данные, необходимые для теней или геометрии.

CPU хранит один результат проекции для статичной сцены. Цена этого кеша:
в приведённой тяжёлой сцене managed heap вырос примерно со 111 до 164 МБ.
Кеш ограничен одной сценой, последовательные повороты не накапливают историю.

LOD и instancing не добавлены: измерения указали на проекцию рельефа, а после
исправления кадр камеры OpenGL занимает около 2.8 мс в этом замере. Усложнять
модели дальних объектов пока не требуется. Понятная настройка качества меняет
разрешение теней: 256/512/1024, сохраняя геометрию, seed и расположение объектов.

Повторный запуск матрицы из корня (открывает окно macOS):

```sh
TERRAIN_SMOKE_RENDER_ONLY=1 TERRAIN_BENCHMARK=after ./run-mac.command --smoke-test
```

Команда перезаписывает `performance-after.csv`. Для воспроизведения старых
значений нужен код до оптимизации; смена имени файла не возвращает старый рендер.
